Overview

Block Cipher is a compact encoder/decoder that turns plain text into structured block output and back again. It is designed for quick experimentation with versioned formats, optional keys, and real-time feedback.

The UI focuses on clarity: two mirrored columns for input and encoded blocks, live character counts, and a small compression readout to help compare original and encoded sizes.

Highlights

Live Encode + Decode

Edit either column to transform text in place without manual copy steps.

Version Selection

Choose a specific format version or let the tool pick automatically.

Optional Key

Add a passphrase to personalize output and keep encodings consistent.

Compression Snapshot

See the size tradeoff between original text and encoded blocks.

Usage Notes

Paste or type text on the left to generate blocks on the right. Paste encoded blocks on the right to restore text on the left. You can switch versions at any time; the output will update on the next edit.

Tip: if you use a key, keep it consistent when decoding so you can recover the original text.
